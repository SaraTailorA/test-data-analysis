# Dataset Fiche

## E-Commerce Sales Performance Analysis

**Source:** Kaggle — E-Commerce Sales Performance Analysis

**Rows:** 5,000

**Columns:** 12

**Domain:** E-commerce and sales performance.

This dataset contains information about orders, customers, product categories,
regions, payment methods, quantities, prices, discounts, delivery times,
customer ratings, and revenue.

The dataset was selected because it contains temporal, categorical, and
numerical variables that allow the development of relevant business questions
and an end-to-end ETL and BI workflow.
